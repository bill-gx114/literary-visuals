# 文学意象转译 · literary-visuals

把诗歌、小说、散文和摘抄转化为有材质与情绪的视觉作品。先核对出处与上下文，再创作；不把所有句子套成同一种画面。

## 安装与使用

本包用于支持本地 Skill 的 Agent。Codex 用户把 `literary-visuals` 文件夹放进 `~/.codex/skills/`（或自己配置的技能目录）。如果界面尚未识别，可新开聊天或重新加载技能列表。

示例调用：

> 使用 $literary-visuals，把这段文字转成适合收藏分享的动态作品：……先核对出处，保留材质感，给我带文字和无字的图片。

其他 Agent 可读取 `SKILL.md` 执行相同流程，安装发现机制需遵循其自身说明，本包不承诺所有宿主都支持同一安装路径。

## 包里有什么

- 出处核验、文学意象转译、艺术指导与验收规则。
- 「涌」「暂歇」「伪天」三份参考的规格、着色器与解释。
- `assets/previews/` 中有可直接打开的三份独立 HTML，不必先运行构建命令。
- 独立 HTML 构建器；网页内置 1600×2000 PNG 和约 12 秒视频导出。
- FFmpeg 视频转 MP4 工具。

构建器只需 Python 3.9+；浏览器需支持 WebGL。网页可离线打开，无第三方网络库。检索能力由宿主 Agent 提供。视频格式取决于浏览器，优先 MP4，否则为 WebM；转码需已安装的 FFmpeg。

制作命令和规格见 `references/production.md`。此 Skill 不自动上传作品或发送到社交平台。短句、来源说明、创作解释分别保留，不能把不明来源标为原创。
