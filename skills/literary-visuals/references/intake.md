# 生成前选择

这是创作需求收集，不是操作授权。先解析用户文本和已给定的选择，问缺失的字段；不要重问可直接从当前对话确认的答案。用户要求修改此 Skill、解释原理或评审已有作品时，不弹创作问卷。

## 工具与等待

优先使用当前宿主提供的交互式提问工具，例如 `request_user_input_async`。仅在工具实际可用的模式下调用它；其他宿主使用等效工具。四个问题尽量一次展示。工具只允许三个问题时分两轮，不把多个维度混在一个含糊选项中。工具支持单选时，以“组合交付”承接多格式需求；始终允许自由输入。

推荐项排第一、注明推荐理由，但预选不等于已提交。此流程由用户要求先选后生成：未答复时仅继续出处研究，保留待答问题，不凭等待时长替用户作答，不生成付费素材、正式图片或视频。需要让出对话时简述正在等哪几项。若用户明确委托“都由你决定”，即可选择并继续，不要求再按一次确认。

无交互工具时，用同一组紧凑选项请用户按编号回复；明确是文字选项。不能用一个无法把答案返回 Agent 的装饰性 HTML 表单假装完成收集。

## 四个维度

### 1. 画面表达

标题示例：“这段文字，你希望怎样呈现？”

- 交给你判断（依据文本推荐一种表达）
- 抽象材质（通过色域、层理、空间和运动表达意象）
- 绘画意境（水墨、油画、版画或拼贴，可在自由输入中指定）
- 具象场景（可辨认的场景与光影，仍保留文学语境）

题材/体裁可自动识别；不让用户在“诗歌、东方、西方、图片”这类混合维度中选择。给出当前环境能执行的选项；具象或绘画若需额外工具，先确认可用能力，不能收完答案后擅自改成抽象。

### 2. 交付形式

标题示例：“你希望拿到什么成品？”

- 图片 PNG（保存、发图、收藏）
- 视频 MP4（可直接播放和分享的短片）
- 交互网页 HTML（浏览器打开，可暂停、调节画面）
- 组合交付（请补充图片、视频、网页中的组合）

不把 HTML 叫作视频；HTML 不等于已托管的分享链接。若用户选组合但未明确内容，追问组合，不自动当成全选。选择单一格式时只交付该成品，其他格式可作为内部制作材料。

视频同时提示默认“12 秒、缓慢、无声”，让用户可以一并改时长。明确确认视频选项且没有更改提示参数时，采用该提示的默认值。用户希望配音、配乐或精确时长时再针对性确认；不要默认扩展一整页高级设置。

### 3. 尺寸与用途

标题示例：“选一个画幅，括号里是建议使用场景。”

| 选项显示 | PNG 像素 | 视频像素 |
| --- | --- | --- |
| 3:4 竖版（小红书图文／竖版海报） | 1536×2048 | 1080×1440 |
| 9:16 全屏竖版（抖音／视频号竖屏） | 1440×2560 | 1080×1920 |
| 16:9 横版（B站横屏／演示／电脑观看） | 2560×1440 | 1920×1080 |
| 1:1 方形（朋友圈方图／多平台图文） | 2000×2000 | 1080×1080 |
| 4:5 竖版（作品展示／朋友圈竖图） | 1600×2000 | 1080×1350 |

按已知输出类型在选项里附上对应像素，例如“1080×1920 · 9:16（抖音／视频号竖屏）”；多格式时显示两种像素或在配置摘要里列明。自由输入接受自定义比例/像素；不要额外造一个与工具自动“其他”重复的选项。只有比例未给像素时用上表，并在生成前摘要告知。

平台括号是本 Skill 的构图用途建议，不是官方唯一尺寸或对所有上传入口的承诺。确实需要发布或精确封面适配时核对当时的官方要求，区别封面、正文图片、视频画面。资料线索：[小红书分享接口](https://agora.xiaohongshu.com/doc/ios)明确不同资源有裁切规则；不能把一个接口的要求套到全部平台入口。

HTML 随窗口等比缩放，选定比例仍约束作品画布，不拉伸填满整个网页。选多画幅时分别设计构图并导出，不能把同一张图强行拉长。竖屏短视频的文字留出边缘空间，不压到播放界面常见操作区。

### 4. 画面上是否展示原句

标题示例：“作品里要保留这句文字吗？”

- 带原句（另附已核实的简短出处）
- 纯画面（不含原句、署名和标题）
- 两版都要（相同构图的带字版与无字版）

这里指用户的原句，不是替用户新写营销文案。短句原样保留；长摘抄放不下时让用户选关键句，或在已获得“由你选句”授权后摘取，不能自动改写成相似金句。未核实的署名不印入画面。无字作品的出处单独存放。

## 回答后的配置

保存 `request.json`，例如：

```json
{
  "text": "用户原文",
  "visual_expression": "abstract-material",
  "formats": ["png", "mp4"],
  "ratio": "3:4",
  "text_mode": "both",
  "duration_seconds": 12,
  "audio": "none",
  "selection_basis": "explicit"
}
```

推荐项与用户确认的选项要区分。只有真实收到回答后 `selection_basis` 才是 `explicit`；用户委托判断时是 `delegated`。未完成的配置不假装完整。

完成后用一句话收束并直接生成：“按抽象材质、3:4 竖版、图片＋12 秒无声视频、带字与无字两版制作。”无需额外审批。将比例、格式与文字模式写入 `delivery`，见制作参考。

## 行为验收场景

- 仅发一段文字：询问四个缺项，等待回答；此时可研究出处。
- “9:16 的无字 MP4，抽象一点，12 秒”：四项齐全，直接研究并生成，不再弹四问。
- 只回答“无字”：保存此项，继续等待剩余项，不把无字推导成图片。
- “都由你决定，直接做”：说明推荐配置后执行，不因问卷停下。
- 选“组合交付”未列格式：仅追问组合内容。
- 选 HTML：交付可打开的独立 HTML，不声称有公网链接。
- “把刚才的视频改成方形”：保留风格、文字和时长，只重做方形构图。
- “给 Skill 加选择框”：修改 Skill，不误触发另一次作品生成。
