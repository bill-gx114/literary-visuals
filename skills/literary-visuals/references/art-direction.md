# 艺术指导

## 本次已认可的方向

作品可以不描绘“星、树、月亮”，但应保留文字中的重量、间隔、牵引、停顿与尺度。用户明确偏好「涌 / 时间的切面」，也接受「暂歇」和「伪天」作为方法案例。其他早期试作不代表所有风格都已被认可。

- 材质有内部结构：矿物的层理、纸的吸收、薄膜的张力、凝胶的滞后；纹理不只是统一铺一层噪点。
- 高级感不是黑底、金线、大留白或抽象的同义词。依据文本选择，不将这几项设为必选装饰。
- 抽象仍须具体：写下“什么在挤压什么”“哪里松开”“什么无法对齐”。“唯美”“电影感”“高级”不足以指导绘制。
- 空间有主次：选一个主要关系，少量辅助关系。保留足以让视线停留的区域。无需每个名词都有对应物件。
- 动作有意义：涌动应有方向与阻力；喘息应有短暂释放与残余压力；记忆扰动可局部错位，不等同随机抖屏。避免快速闪白、连续缩放、无关漂浮粒子。
- 静止也成立：构图与材质不能全靠动画补救。原句可以隐藏；文字本身应有可读性。

## 从文本到艺术决策

| 要理解的关系 | 可考虑的设计变量 |
| --- | --- |
| 阔、远、微小的人 | 主体与负空间比例、边界裁切、细节尺度 |
| 涌、压、垂、停 | 方向、速度、曲率、压缩、延迟、局部静止 |
| 干燥、余热、窒息 | 反光强度、色温、颗粒尺度、空气感 |
| 柔软与尖锐并存 | 边缘硬度差异、局部断裂、张力 |
| 回忆或失真 | 对齐关系、残影、遮挡、有限范围的相位差 |

这些是候选工具，不能构成“关键词→固定滤镜”规则。

## 修改时

把用户反馈转换为具体可观察变化，例如“减少镜面反光”“降低黑块占比”“保留粗粝但减弱噪点”。保留用户喜欢的部分，不因一次反馈重写全部风格。一次作品中的喜好不自动成为所有人的永久默认。

## 失败迹象

- 只改句子和色相，结构完全不变。
- 渐变、噪点或波浪本身承担了全部“意象”。
- 云必须是云形，心必须画成心脏；把隐喻直接物件化。
- 无上下文地把所有文学都做成宁静风景。
- 大段解释才能说服观看者这幅作品与文本相关。
