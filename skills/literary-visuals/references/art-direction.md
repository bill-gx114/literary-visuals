# 艺术指导：从语义关系选择表达

## 先锚定，后定风格

把核心判断落到可见证据：读者应当能指着画面说出“这里的阻隔/牵引/反差对应这句话”。联系可以隐含，不能完全依赖署名或作者生平。材料、空间、色彩与运动中，至少一种承担具体含义。

优先决定三个问题：观看者站在哪里；视线先遇见什么、在哪里停住；画面最不可替换的关系是什么。再选主体和媒介。叙事文本不一定需要人物，抽象文本也不一定没有可辨形象。

## 风格不是随机抽签

内部比较二至三个方向，差异至少落在构图或表达机制上。例如“近距离的物质挤压”“远距离的空间隔断”“轻快重复中的一个缺口”，而不是三个滤镜。若用户已指定水墨，比较湿墨渗透、干笔断裂与留白的作用，不擅自换成摄影。

下列方法是可用语言，不是分类→风格的一一对应：

| 视觉语言 | 在什么情况下值得考虑 | 需要看见的形式决定 |
| --- | --- | --- |
| 摄影感/电影式场景 | 受限视点、身体距离、现实中微小但关键的痕迹 | 焦点、镜头距离、遮挡和光源；道具不能抢过主关系 |
| 油彩/粉彩/水彩/版画 | 触感、记忆、紧张或松弛能由笔触与边缘表达 | 笔触方向、厚薄、干湿和虚实；不是套一层画布纹理 |
| 剪纸/拼贴/纸雕 | 时间错位、分隔、脆弱或叙述层次 | 切口、叠层、真实投影与连接；不固定复古纸黄 |
| 极简几何/负形 | 条件、悖论、距离、依存等关系 | 形状之间可读的因果、比例和接触方式；非装饰符号 |
| 材料抽象/程序场 | 压力、流动、积累、渗透等过程本身就是内容 | 材料内部结构与方向；噪点和渐变不独立承担意象 |
| 超现实物象/舞台 | 荒诞、否定、字面与情绪的冲突 | 一个清晰的不可能关系；避免堆奇物和无关隐喻 |
| 字形与空间共同构图 | 词语的反复、断裂或语言本身参与意思 | 字体仍准确可读；无字版需独立设计，不能删字即空白 |
| 叙事蒙太奇/分镜 | 变化跨越时间，仅一个时刻不足以表达 | 镜头之间的关系和情绪转折；不要只给静图加推拉 |

## “高级”落实为可观察的决定

- **主次清楚**：一个主张力，有限的辅助信息。简约或繁复都可以，密集区域也有组织。
- **材质可信**：纸的吸收、油彩的厚度、金属的反射、薄膜的张力来自不同内部结构。纹理不是统一噪点覆盖。
- **形式有必要**：饱和色、硬边、粗粝、明亮、幽默和动感都可成立；不把高级等同于黑金、低饱和、宋体、大留白或慢镜头。
- **留白有作用**：体现距离、停顿、缺席或阅读空间；不是把内容缩小到中央。
- **不靠解释补救**：若视觉决定无法指向某个锚点，删除或重做，别为它补写宏大隐喻。

## 多变但不失去文本

若当前任务可访问最近三件作品，简单比较 `主体 / 构图 / 媒介 / 色彩逻辑 / 运动`。不要求五项全变，也不为差异强加不相关材料；优先改变反复出现且缺乏文本依据的主体或构图。连续沿用“孤独小人+大风景”“上图下文”“层理+亮缝”时要给出文本理由，不能只说用户以前喜欢。

用户要求系列时保留系列识别，把变化放在关系与节奏；不要为了多样性破坏明确的系列风格。历史作品不是质量证明，不推导为用户永久偏好。

## 动作与静止

写清谁在动、方向、阻力、节奏与终点；或为什么静止更准确。哀伤未必缓慢，欢乐未必飘粒子，力量未必爆炸。运动可以是张力积累后停住、重复中的缺失、靠近却无法触及。低频和局部运动是舒适默认，文本依据与用户选择优先；避免无意义闪烁。

新画幅、新文字范围都要重看构图，不拉伸旧画。修改时先描述可观察问题，再修改相关变量；保留已成立的部分。
