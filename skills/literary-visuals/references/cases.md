# 创作案例与反例

随包的 JSON 规格位于 `references/examples/`，着色器位于 `assets/shaders/`。它们是早期的三件材料抽象案例，不代表全部风格范围，也不是新作品的质量下限或默认路由。新任务先完成语义锚点与方向比较，再选择是否参考。

## 涌 / 时间的切面

文本：杜甫《旅夜书怀》“星垂平野阔，月涌大江流”。此案例以尺度和推动关系组织画面，不据此推导后续文本都适合矿物抽象。

- 转译关系：细密层理与广阔色域的尺度反差；一股持续推进的内部力量。
- 方法：朱砂、赭金与墨色的非对称切面，低频形变和细密材质。避免画出星星、圆月和江岸。
- 出处：2026-09-28 打包时对照[全诗](https://zh.wikisource.org/wiki/旅夜書懷)核实，状态 `confirmed`。前有独夜舟，后以天地间的沙鸥自况；辽阔与个体漂泊的尺度反差是本次解释的依据。矿物配色是艺术选择，不宣称原诗描写朱砂。
- 规格：`examples/surge.json`；着色器：`../assets/shaders/surge.glsl`。

## 暂歇

文本为用户提供的《局外人》摘抄，画面使用末句“傍晚应该是一段忧伤的喘息”。

- 核实位置：第一部第一章。法文原作：https://www.fadedpage.com/books/20150715/html.php
- 相同中文措辞线索：https://wenxue88.com/juwairen/jwr_0101.html
- 中文译者、具体版本和页码未可靠确认。
- 当前叙述是母亲葬礼段落的白昼。傍晚是默尔索想到母亲生前散步时的想象；后文回到难以忍受的烈日。
- 转译：压力暂时松开但余热仍在。红土与灰绿沉在下方，灰紫空域、窄亮隙、缓慢舒张。交互对照的是两种感受，不声称现场从白天过渡到夜晚。
- 规格：`examples/truce.json`；着色器：`../assets/shaders/truce.glsl`。

## 伪天

用户提供的片段包含塑料气味、凝胶地平线、人造且破漏的天空、煤黑软云和搏动的黑暗之心。

- 有限的中文精确与英文意象检索未得可靠匹配，状态 `unverified`。不推测作者与书名，也不沿用前一段的加缪署名。
- 转译：苍白薄膜与低饱和紫灰，哑黑块的局部收缩，层片挤压，裂口、错位与低频残影。
- 不将不明指代的“他们”解释成具体人物；作品名「伪天」由本次创作提出，不是原作标题。
- 规格：`examples/artificial-sky.json`；着色器：`../assets/shaders/artificial-sky.glsl`。

## 《合欢树》长段落：场景相关仍可能不足

真实试作采用旧院子绘画加下方完整原文。它保留了通道受挤、树不可见与墙上影子的空间线索，但上图下文的固定分区、复古街景和大段正文，仍可能让读者先读到“旧北京插画”，而不是亲近与不可抵达的并置。用户随后反馈整体效果不尽如人意，希望按文本与意象分类并增加风格变化；不能把该反馈夸大成对某个具体细节的明确否定。

后续可比较以下方向，尚未因此自动视为成品：

- **空间错位的纸雕**：近处通路与深处生长痕迹仅差一层，却无法连通。主体是距离关系，不是空巷美景。
- **受限视点的绘画**：把遮挡放到构图主位，温暖的邻里细节只做辅助，不逐一画茶、烟、人物和树。
- **透光的材料装置**：内层影子仍延展，外层边缘封住接近路径。需防止过度抽象后只有泛化的“裂缝与光”。

这些方向都须再看实际画面；不能仅因分析更详细就声称改进成功。原文见[《合欢树》](https://www.aisixiang.com/data/38178.html)，具体选集版本未确认。

## 不同机制的对照（原创评测句，非文学引文）

| 测试文本 | 值得尝试的形式关系 | 不应自动选用 |
| --- | --- | --- |
| “风一来，晾衣绳上的白衬衫就争着做帆。” | 白布的鼓起与有组织的节拍；鲜明平涂或轻盈版画 | 灰色独行人、梦幻光粒 |
| “每一把锁，都把自己的钥匙关在里面。” | 几何壳体与内部钥匙互相封闭；清晰悖论 | 一本书漂在宇宙中 |
| “掌声整齐得像一堵墙。” | 密集重复单元围合成边界，秩序带来压迫 | 热烈舞台上的庆祝人群 |

同一情绪也有不同机制，同一物象也会承担不同感受。表中方法只是可检验的候选；最终以用户选择、语境与看图结果为准。
