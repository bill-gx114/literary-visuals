# 成品解析

默认每次交付图片、视频或交互作品，都在回复中提供一份简明解析，并保存为作品目录的 `interpretation.md`。它是面向观看者的阅读说明，与技术检查 `review.md`、背景资料 `research.md` 分开。无字作品也附外部解析，不改变用户选择的画内文字模式。明确要求只给成品时省略回复解析。

在实际看过成品后写解析。通常用三至四个短段，约 250–450 个汉字；按作品复杂度调整，不为字数堆砌。无需固定标题，但以下内容应有实质交代：

1. **文本核心**：这一段的关系、矛盾、转折或感受是什么；从具体原文出发，不复述整段故事，不将一种阅读说成唯一原意。
2. **画面如何对应**：指认一至三个成品中确实可见的位置、动作、形态或变化，说明它们与文字的关系。视频交代节奏与转折，交互交代观众的操作为何有意义。不要解释画面里并不存在的细节。
3. **为什么采用这种风格**：指出作者／该作品的语气、可靠的时代参考如何影响媒介、空间或色彩；明确哪些为文献事实，哪些为本次创作判断。未采用同时期画风时说明文本上的理由，不为现有成品补造历史血统。原创、未知来源或资料不足时据实说明，仍解释视觉选择。
4. **文字与构图的取舍**：为什么选这个连续片段或保留全文，文字位置、留白、画幅如何组织观看；说明舍去其他情节的理由，而非只报像素参数。

文末或相关句旁附精简出处信息与必要链接，区分作品确认、译文版本未核实、背景资料不足。不要把来源与完整生平塞进画面。尺寸、格式与下载入口列在成品旁即可。

交付前核对解析是否忠于成品：所谓涟漪、遮挡、对照是否可见，所谓时代风格是否有证据，选句是否真的连续原文。若缺少关系，优先修正作品；解析不能替一幅通用背景建立不存在的联系。补写已完成作品的解析时，区分原创作依据与事后研究所得。
