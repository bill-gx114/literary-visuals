# 文本分型与文字处理

先区分“需要理解多少内容”和“画面上需要读多少字”。完整输入用来理解；实际展示范围服从用户选择。以下长度是中文及类似密度文本的起点，不是自动风格路由；英文按词长、实测宽度与阅读时间判断。

## 两个独立维度

### 阅读体量

| 类型 | 初步识别 | 创作任务 | 文字安排 |
| --- | --- | --- | --- |
| 短句 | 通常不超过 35 个可见字符，单一关系 | 找到一句话中真正起作用的动词、反差或省略 | 可完整显示；让字与画形成重心，不必放大到口号 |
| 长句/短段 | 约 36–120 字，可能有转折或并列 | 把转折前后放到同一空间关系或时间动作中 | 按语义断行；区分主次但不擅改字句 |
| 长段落 | 通常超过 120 字，多句、多动作或多时间层 | 提炼一个主张力，用少量锚点保留独特性；不画故事清单 | 先选择全文、授权节选或纯画面；文字负担需在生成前解决 |
| 多节/多场景 | 无论字数，含不同视点、时间、说话者 | 决定保留一个张力，还是以组图/分镜承接变化 | 若需要改变单图交付为组图或延长视频，先说明并取得对应选择 |

阈值是检查提醒：二十字也可能有多层讽刺，二百字也可能只围绕一个停顿。字数不会自动决定媒介、色彩或主体。

### 表达机制（可组合，选一项主导）

| 机制 | 要识别什么 | 适合转译的关系 | 常见误读 |
| --- | --- | --- | --- |
| 感官意象 | 光、声、触感如何作用在身体或空间上 | 边缘、密度、吸收、距离、重力 | 出现“冷”就涂成蓝色 |
| 关系/缺席 | 谁靠近谁、什么遮住什么、什么留下痕迹 | 遮挡、负形、不对称、视点限制 | 悲伤固定配背影、空椅或空巷 |
| 动作/变化 | 主动与被动、阻力、方向、速度、完成或未完成 | 张力、形变、跨越、断续、停顿 | 把动作变成无目的粒子漂浮 |
| 叙事/记忆 | 眼前、过去、愿望分别是什么 | 局部错位、复现、透叠、前后景 | 把想象或已经失去的人画成现实在场 |
| 思辨/悖论 | 句子中的条件、否定、因果或自相矛盾 | 尺度冲突、边界倒置、互相依赖 | 配星空、书本或泛化宇宙当“哲理” |
| 讽刺/荒诞 | 字面态度与真实关系是否相反 | 秩序与异常、重复与断裂、材质不相容 | 只画字面的欢乐或悲伤 |
| 喜悦/轻盈 | 活力的方向、节奏与具体触发物 | 开放、弹性、明快色差、疏密节拍 | 为追求“高级”一律降饱和与放慢 |

情绪写成关系或轨迹，如“被接纳 → 不能进入 → 不急着回去”。“治愈”“忧伤”“自由”本身不足以支持构图。

## 生成前解决长文显示

在原来的文字问题中直接给长文适用选项，不另开一套问卷：

- **保留全文**：接受阅读型排版，先检查它是否能与主体共享画幅。
- **由你选关键句**：授权从原文截取连续片段，不改写；其余文本保留在外部说明。
- **纯画面**：通过画面表达整段，画内无标题和署名。
- **带字与无字两版**：同时说明带字版是全文还是授权节选。

用户只说“带字”时，已有全文约定就沿用；短文本默认全文；长文本也不自行截取，先尝试可读的全文构图。只有确实放不下、必须改变交付或删节时才提出具体选择。“风格你决定”不授予节选权；“全部你决定，包括选句”才覆盖选句。

保存 `full_text` 与 `quote`：前者是收到的完整文本，后者是实际印出的连续原文。`text_selection.mode` 为 `full` 或 `excerpt`，节选还记 `approval: explicit | delegated`。多片段引文需要人工标清省略与顺序，并用支持该结构的制作流程；随包构建器只支持一个连续节选。

## 容量检查不是缩字比赛

1. 先给主体和文字各自明确的位置，计算按目标字号实际能排多少行，而后生成底图。全文排版可以是侧栏、沿空间结构排布、留白中的多段或用户接受的阅读页；不默认一半图片一半正文。
2. 以最终展示宽度检查字体。手机约 390 CSS 像素宽时，主要正文通常需要约 13–18 CSS 像素；这是自检起点，不是所有字体的硬标准。放大导出像素不会增加手机上的物理可读性。
3. 字放不下时，先调整阅读区、构图和行距；不要无限缩字，也不要用模糊背景、遮住关键锚点或删掉中段来“通过”。若仍冲突，再让用户在节选、组图或阅读型成品间选择，解释实际冲突。
4. 中英文按自然断行；中文避免标点开头和左括号结尾，英文优先词边界。保留段落、否定词和情绪转折；不把“悲伤也成享受”简化成“享受”。
5. 视频用实际阅读耗时验收：字多不能在 12 秒里一闪而过。先试读完整一遍，计入画面理解与转场留白。时长不足时保持用户原时长并提出节选/延长选项，不暗自延长或丢字。字幕分段应对应叙事段落，变化不靠快速打字动画。

## 《合欢树》这类长段落

这段的主关系不只是“旧院子很美”或“我很悲伤”，而是邻人的亲近、空间的阻隔与生命继续生长的并置。“摇车慢慢走”是退离与停留在情绪中，不是随便一条安静街道。母亲与树的关系须由已核实的上下文支持。

可以用空间遮挡、具有触感的层片或受限视点建立这种关系；并不强制画树、轮椅、人物、茶烟和厨房。若选真实街景，需要让受限通路或生长痕迹成为构图中的决定因素。单纯复古滤镜加全文，只证明场景相关，未必证明情绪与张力成立。
