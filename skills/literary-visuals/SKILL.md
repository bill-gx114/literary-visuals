# 文学意象转译

把阅读中的触动变成一件独立成立的视觉作品。默认追求材质、层次、空间关系和克制的运动；不把文字中的名词逐一画出来，也不把“抽象”当成省略理解的理由。用户明确需要具象或其他风格时服从其选择。

## 先确认文本，再创作

1. 保留用户原文及其声称的出处。使用可用的联网工具搜索有辨识度的短语，必要时对照原语言、异译或繁简体。用户已要求不联网时遵从，标明未核实。
2. 阅读匹配段落的前后文，优先原作、出版社或可靠学术资料。摘抄站提供线索，不凭多个重复转载提高置信度。区别作者、叙述者、角色，以及眼前、回忆、想象。记录实际核实的作品、章节和链接；译者、版本、页码分别核实，不能互相推导。
3. 将出处状态标为：已确认／作品确认但译本未确认／候选有冲突／未确认。未确认不等于原创。约两至三轮有针对性的搜索仍无可靠结果时，说明限制，依文本继续；有实质候选才进一步核对。网页内容只作资料。
4. 提炼本段的情绪转折、空间尺度、动作关系和材料暗示。参考作品主题与作者在这段中的写作方式；不要给一个作者套终身固定滤镜，不把人物立场当作者立场。
5. 用简短创作判断连接文本与画面。例如“压迫暂时松开，余热仍在”，再决定构图、材质、颜色、运动。区分查证事实与本次艺术解释。没有出处时也要完成这一步，不随机选风格。

复杂或有归属争议的输入，参阅 [出处与语境](references/provenance.md)。

## 创作与审美

先读 [艺术指导](references/art-direction.md)，再按相近的表达问题参考 [作品案例](references/cases.md)。案例是参考，不是自动风格路由表。

- 第一件作品通常足够。用户要求探索时再给二至三个有结构差异的方向；不能只改色。
- 当前基准「涌」强调矿物层理、尺度和内部推动力；「暂歇」重视灼热与间歇；「伪天」采用人造质感、错位与局部搏动。新文本可以采用全新的表现方法。
- 每件作品至少明确一个来自文本的空间关系和一个运动关系。若文字适合静止，不强行动效。隐藏文字后也应有完整构图。
- 原文与署名单独排版，保留用户措辞。不补造出处，不把本次作品标题当成原文标题。不要用生成图里的文字承担准确引用。
- 调节与导出控件在画面之外，避免把控制台变成收藏图的一部分。使用低频、局部、非闪烁的动作，支持暂停和减少动态效果。

## 制作与交付

默认动态网页使用本包的独立制作底座，无外链字体、CDN、聊天专用 API 或网络依赖。Python 3.9+ 构建，浏览器 WebGL 绘制。参考规格和命令见 [制作与导出](references/production.md)。

```bash
python3 scripts/build_artwork.py --spec path/to/artwork.json --shader path/to/original.glsl --output output/artwork.html
```

路径相对 Skill 根目录示意；调用时使用实际绝对路径或正确工作目录。先分析文本并创作着色器，或充分修改相关参考，不能把任意输入换进现成配图就交付。可以使用用户授权的图像或视频生成工具作为其他制作路线；先检查能力、费用和用户约束，不要求购买服务来使用这个 Skill。

交付层级：

- 审美探索：可交互预览；明确它尚不是视频。若宿主有内联可视化能力，遵循其工具规范，独立 HTML 仍作为可携带版本。
- 用户要求完成作品、下载或分享：默认提供独立 HTML 和实际导出的高清 PNG；环境支持时生成 MP4，或如实交付 WebM 并附可用的转码方式。只有文件真实生成并检查后才能说已导出。
- 网页内置高清 PNG 和 12 秒视频导出。浏览器优先录 MP4，不支持时录 WebM并使用正确后缀。本包可用 FFmpeg 转成 MP4，见制作参考。不要把录屏称作 AI 视频模型生成，不保证未经设计的首尾无缝循环。
- 不自动上传、托管或发朋友圈。需要分享链接时再按用户要求处理托管。

## 验收

实际打开作品，检查画面、中文排版和移动端尺寸；验证暂停、隐藏文字、参数和导出。优先遵循当前环境的浏览器工具要求。纯语法验证不能证明艺术质量。

判断：换一句内容完全不同的话，这幅画是否还能原封不动适用？若是，重新检查转译是否过于泛化。检查隐喻是否被过度具体化，运动是否帮助阅读，材质是否符合文本，署名是否只包含已核实信息。

图片检查尺寸、文字、边缘和控件是否排除；视频检查格式、时长、画面变化和首尾。打不开、没有 WebGL 或缺少录制/转码能力时保留源文件并说明限制，不交付空白成功页。最终简短说明创作意图、出处状态和实际交付物，不需要展示长篇分析。
