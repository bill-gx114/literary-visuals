# v0.2 验证记录 · 2026-09-29

本次目标：让文本决定不同的视觉表达，并让画面与原句的关系可以被具体指认。评审者为本次执行的 Agent；未进行独立读者盲测，不报告识别率或“高级感分数”。

## 两件实际视觉试作与一次修正

底图使用内置 imagegen，提示词保存在 [image-prompts.json](image-prompts.json)。测试句为本次原创文本，未冒充名家引文。它们仅用于验证创作方向，未作为带字文学成品进行像素尺寸交付。

### 轻盈句

“风一来，晾衣绳上的白衬衫就争着做帆。”

实际文件：[joy.png](joy.png)。白布向外鼓起，线绳维持张力，两条斜线和近大远小的裁切组织节拍；高饱和蓝、白与小片暖红强化轻快。这里的主体和空间不沿用旧院子或矿物层理。

- 去字后仍能看见布面、拉力与风的共同方向。
- 换成同物象的“衬衫沉沉地挂着，风停了”时，鼓起的体积和斜向节奏会冲突。
- 换成同样喜悦但没有布面张力的“灯都亮了，大家终于回家”时，画面不再能直接承接关系。
- 局限：也可能被理解为普通晾衣场景；“争着”的拟人程度仍依赖原句。未证明所有读者都会读出同一感受。

### 悖论句

“每一把锁，都把自己的钥匙关在里面。”

初稿：[paradox-before.png](paradox-before.png)。问题是盒体虽封闭、钥匙可见，但没有明确锁孔，容易读成陈列盒，说明名词出现不等于关系成立。

针对修改：增加外侧锁孔，收窄观察缝，使钥匙宽部被壳体遮住，保留视角、材质与重复的封闭体。修改提示保存在 [paradox-edit-prompt.txt](paradox-edit-prompt.txt)。

结果：[paradox.png](paradox.png)。现在外部的开启机构与内部不可取出的钥匙同时可见，关系比初稿清楚。与轻盈句相比，媒介、主体、构图和色彩逻辑均不同；不是同一画面换色。

- 去字仍保留“解锁物被困住”的矛盾。
- 换成“钥匙终于找到了自己的锁”时，封闭和无法取出的状态不匹配。
- 局限：这是视觉隐喻，不能从图片验证真实机械是否可开；不据此宣称观众必然理解“自己的”。

这次失败促使验收明确区分“相同物件出现”和“物件的关系可见”。两件试作支持新规则的可执行性，不证明整个输入空间已覆盖。

## 十个行为任务的桌面推演

输入：[prompts.json](../../skills/literary-visuals/evals/prompts.json)。以下是阅读新规则后的路线检查，不是十件图片的实际生成结果。

| 任务 | 本次处理判断 | 检查结论 |
| --- | --- | --- |
| short-absence | 温度残留与座位缺席并置，先比较近物静物与空间负形 | 短句不必抽象，不补署名 |
| long-sentence-turn | 光的位置不变，人对光的理解改变；否定词保留 | 不把非迎接的光画成救赎 |
| long-full | 记忆中的伞摊与眼前玻璃门分层；文字先留完整阅读区 | 全文不擅截；容量另有真实浏览器检查 |
| excerpt-permitted | 可选“如今门还是从前那扇门，街道却宽得让我不知道该站在哪里。”，保留完整输入 | 连续原文，授权范围明确 |
| paradox | 封闭壳体、外部锁孔和内部钥匙 | 已实际试作并修正一次 |
| irony | 密集重复形成阻挡，抑制字面庆祝构图 | 氛围不自动照搬名词 |
| joy | 鼓起的布面与斜向节拍 | 已实际试作 |
| series-constraint | 保留黑白木刻，用裁切和节拍变化 | 系列约束优先，不强行换媒介 |
| video-overload | 全段不可能在 3 秒正常读完；需用户选择延长或授权节选 | 不暗改时长，不擅自删文 |
| partial-intake | 提出四项缺项，等待真实回答 | 推荐值不是确认值 |

## 程序与实际导出

- Skill 元数据验证通过。
- Python `unittest`：9 项通过，覆盖画幅、交付规格、全文一致性、连续节选、授权记录及无效排版参数。
- Node `node:test`：10 项通过，覆盖中英文断行、固定字号、长文溢出、署名碰撞及多尺寸布局。
- 三份历史 HTML 用当前代码重新生成；浏览器实际打开「涌」，验证文字显示/隐藏与暂停控件。
- 浏览器以原创长段落执行全文排版并导出真实 PNG，文件头为 1536×2048。该技术测试复用旧着色器，只证明文字容量及导出，不作为画文契合样例。
- 过量文本显示“原文超出预留阅读区域”，实际点击带字导出返回失败，不生成缺字图片；没有通过缩字绕过。
- 3 秒视频实际导出为 H.264 MP4，ffprobe 测得 600×800、2.998267 秒。该测试用于排版和录制回归，不是文学视频审美验收。
- 窄屏实测 `innerWidth=480`、画布 440 CSS 像素。浏览器尺寸控制未达到所请求的 390 CSS 像素，因此不声称真实 390 手机窗口已验收；390×520 的布局一致性仅由自动测试覆盖。

字体与换浏览器后的行为、完整叙事视频和真实读者理解尚未验证。程序检查不判断媒介与语义是否契合，也不能自动保证中文在任意设备上的美感。

安装包额外检查：ZIP 完整性正常；从临时目录解压后重跑上述 19 项测试全部通过，并独立构建出「涌」HTML。本地已安装 Skill 同步到本次源码；旧安装保留了本地备份。
